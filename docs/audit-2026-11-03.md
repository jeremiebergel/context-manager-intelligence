# CMI pre-release audit — 2026-11-03

Scope: quality, architecture, results, continuity, security. Read-only; no code changed.
Evidence: `pytest` (421 passed, 9 skipped, 21 s), coverage, `ruff` (select S,B,BLE,F), `radon cc`, manual read of `cmi/store.py` and `cmi/proxy.py`, regex secret/private-name scan of tracked files.

## What holds
- Tests green; coverage 81 % overall (engine 87 %, project_memory 96 %, project_policy 94 %, secrets 100 %).
- Zero runtime dependencies (`dependencies = []`): minimal supply-chain surface.
- Store: dir 0700 / files 0600, `O_EXCL`+`O_NOFOLLOW`, atomic `os.replace`, recall key validated by full-match hex regex before building a path (no traversal).
- Proxy: loopback by default, Host allowlist (DNS rebinding), Origin refused, `hmac.compare_digest` token, non-loopback bind requires token, no request logging of bodies, body size cap.
- No secret pattern in tracked files; no home path / username in code (bench results use `/Users/USER`).
- CI: Linux+macOS, Python 3.10/3.12/3.13, wheel/sdist build + `twine check --strict`.

## Pre-publication hardening (2026-11-03, second pass)

- Cost: the prompt-cache warning (−19% to +53% estimated bill) moved to the top of the README.
- Linux CI reproduced locally (Docker, `python:3.10/3.12/3.13-slim`, clean clone of the export):
  ruff, full suite, `proxy_e2e`, `public_demo`, `cmi-proxy --help` all pass. The 3.10 run found a
  real bug: `sqlite3.SQLITE_BUSY` and `error.sqlite_errorcode` are Python 3.11+, so project-memory
  contention retry crashed on 3.10. Fixed with local constants + message fallback, test added.
  The Console bundle step (needs Node) and macOS runners still only run on GitHub.
- Hermes internals: every Hermes symbol CMI imports is listed in `cmi/hermes_contract.py`
  (`python -m cmi.hermes_contract`); a test fails if a new import is not listed. All 18 resolve on
  Hermes 0.22.5. `resolve_model_threshold` was the one unguarded core import; now fail-open.
- `engine.py`: tool-call classification and shell-path parsing (incl. `shell_written_paths`, CC
  54) moved to `cmi/toolcalls.py` (2,142 → 1,904 lines), re-exported for compatibility. The
  remaining complex methods (`_degrade_tool_call_args`, `_superseded`, `_select_impl`) need
  behaviour-level splits and are left for a reviewed refactor.
- Maintenance: issue/PR templates, private security contact link, monthly Dependabot for
  Actions, a written best-effort support policy in CONTRIBUTING.md.
